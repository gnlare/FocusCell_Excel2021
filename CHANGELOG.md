# Changelog

## 1.0 — 2026-08-17

Initial public release.

- Excel 2021 Focus Cell-style transparent overlay
- Active cell interior remains transparent
- Configurable highlight color, opacity, mode, and selected-cell border
- View-tab Focus Cell and Settings controls
- Hides while Excel is moving/resizing
- Handles zoom, merged cells, frozen/split panes, and Backstage screens
- Actual worksheet cell viewport detection via Excel on-screen hit-testing
- Excludes sheet tabs, scroll bars, headers, and pane split regions from the overlay
- Unified source builds Korean and English XLL editions
- Root `INSTALL\KR` and `INSTALL\EN` output from one build command
